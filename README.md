## 環境構築

1. リポジトリをクローン

```sh
git clone https://github.com/gizumo-education/typescript-lesson.git
```

2. 対象ディレクトリへ移動

```sh
cd typescript-lesson
```

3. パッケージをインストール

```sh
npm i
```
