# 総合課題：タスクボード

本レッスンの総合課題として、実際の開発と同じように**既存のコードベースに機能を追加**します。

## 準備

以下のコマンドで開発サーバーを起動してください。

```shell
npm run dev:taskBoard
```

ブラウザが自動で開き、タスクボードアプリが表示されます。  
起動直後の状態でも、ステータスフィルターとタスク件数の集計はすでに動作しています。

## 課題

**タスク追加機能を実装してください。**

現在、フォームにタイトルと優先度を入力して「追加」ボタンを押しても何も起こりません。  
`src/lesson/taskBoard/taskBoard.ts` にコードを追加して、タスクを追加できるようにしてください。

API の仕様は `openapi.yaml` を参照してください。

### 満たすべき動作

- タイトルと優先度を入力して「追加」ボタンを押すと、タスクが一覧に追加される
- タイトルが空のまま送信した場合、エラーメッセージが表示される
- タスク追加後、ステータスフィルターの現在の絞り込み状態が維持される
- タスク追加後、ステータスごとの件数が更新される
- ネットワークエラーが発生した場合もエラーメッセージが表示される

## 注意点

- `any` 型の使用は禁止です
